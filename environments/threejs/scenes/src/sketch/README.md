# Sketchbook Airfield (source for `03_sketchbook_airfield_constrained.html`, v2 polish)

Upstream: [swift502/Sketchbook](https://github.com/swift502/Sketchbook) (MIT) — a third-person
character / car / helicopter / airplane playground built on three.js r113 + cannon.js, with a
3-cascade CSM sun, a Preetham sky shader and an ocean shader.  The original candidate file
(`orig_v1_*.bak`, 39.6 MB) embeds the unmodified webpack bundle and the upstream GLBs
(world / boxman / car / heli / airplane) as base64 through an "offline asset bridge".

`node` is not available on this machine, so the bundle is **not** rebuilt.  Everything here is a
runtime layer on top of it (build.py + enhance.js); the upstream game loop, physics, input and
scenarios are untouched.

## What changed (v1 -> v2)

* **Colour pipeline** — the renderer output was linear (`outputEncoding` 3000) with sun 2.5 ×3
  cascades + hemisphere 0.9 through ACES, which blew every surface out to white.  Now sRGB output,
  sun 1.45, hemisphere 0.55 / 0.22, exposure 0.95, a light haze (`Fog` 140–900 m) and a slightly
  deeper Preetham sky.
* **PBR surfaces** — the flat 512² placeholder textures of the big surfaces are replaced by Poly
  Haven sets (1k JPEG diffuse / normal / ARM, `MeshStandardMaterial`, `uv2` = `uv` for AO, CSM-patched):
  apron `concrete` → concrete_floor_worn_001, ramps `plaster` → concrete_wall_008 (beige tint),
  `wall_rough` → concrete_wall_006, the 6 m retaining walls `wall_segmented` → concrete_slab_wall,
  the raised bands / plateau `roof` → aerial_grass_rock, the dirt oval `dirt_road` → gravel_road.
  Painted textures (race track, runway, helipad, striped barriers, signs s1–s6) keep their maps and
  only become PBR (the sculptures get a faint plaster normal map).  The car body is tinted red with a
  reflective paint.
* **Props with colliders** — 155 static Poly Haven props (`props.json`, generated by
  `make_props.py`): crates, barrels, jerrycans, propane tanks, generators, tool / storage carts, a
  hydrant, 35 concrete road barriers, 15 street lamps (four on the plaza corners, eight on the raised
  grass bands flanking the track bowl) and a 120 m chain-link fence (61 × 2 m modules) between the
  apron and the runway.  Each instance is dropped onto the lowest walkable surface by a ray (ramp decks
  and overpasses are ignored) and gets a static `CANNON.Box` of its bounding box, so the character and
  the vehicles cannot pass through (verified with keyboard walks, see below).  Metals get a cube-map
  environment captured from the plaza (PMREM), which is what stops the barrels / fence / jerrycans
  from rendering black.  The Poly Haven fence wire is exported without alpha, so its material is
  replaced by a procedural chain-link lattice (`alphaMap` + `alphaTest`); the hydrant model ships two
  variants side by side and the "aged" twin is dropped.
* **Boundary** — the sunken park (x ±165, z ±106) is walled on all sides, so the constrained
  boundary is widened from ±90 m around the spawn to the whole park (`center [0,15,0]`, half
  163 × 104).
* **HUD / API** — `window.BenchmarkWorld` v2 keeps the upstream fields (`getWorld`, `getScene`,
  `reset`) and adds `ready` / `status`, `teleport(x, y|null, z)`, `setOrientation`, `setView(theta,
  phi)`, `setDistance`, `setFirstPerson(on)`, `setHud(on)`, `dismissModal()`, `setTimeScale`,
  `getState()`.  Opening the file with `#benchmark` in the URL dismisses the welcome dialog and hides
  the HUD automatically.

## Files

* `build.py` — patches three unique anchors of the minified bundle to expose `window.THREE`,
  `window.CANNON` and `window.__SB_GLTFLoader`, embeds `pack.json` as `window.__SKETCH_PACK__`,
  `props.json` as `window.__SKETCH_PROPS__` and `enhance.js`, widens the boundary config.
* `enhance.js` — the runtime layer described above (waits for the world and the character, then
  lighting → materials → props → environment capture → API).
* `ph_fetch.py` — downloads Poly Haven texture sets and glTF models (with includes) into
  `assets/sketch/{textures,models}`.
* `manifest.json` + `../common/pack.py` — packs models (KHR_mesh_quantization, **JPEG/PNG images**:
  three r113's GLTFLoader has no EXT_texture_webp; `"webp": false` in the manifest) and textures.
* `make_props.py` → `props.json` — prop placement (world x/z, yaw; y resolved at runtime).

## Rebuild

```bash
.venv/bin/python environments/threejs/scenes/src/sketch/ph_fetch.py --assets assets/sketch \
    --tex concrete_floor_worn_001 concrete_wall_008 concrete_wall_006 concrete_slab_wall aerial_grass_rock gravel_road plastered_wall_04 \
    --model concrete_road_barrier concrete_road_barrier_02 barrel_03 plastic_crate_01 plastic_crate_02 old_military_crate \
            wooden_crate_02 metal_jerrycan_green propane_tank portable_generator industrial_storage_cart tool_cart \
            street_lamp_01 fire_hydrant modular_chainlink_fence industrial_pastic_container
.venv/bin/python environments/threejs/scenes/src/common/pack.py --manifest environments/threejs/scenes/src/sketch/manifest.json \
    --assets assets/sketch --out /path/to/pack.json
python3 environments/threejs/scenes/src/sketch/make_props.py environments/threejs/scenes/src/sketch/props.json
.venv/bin/python environments/threejs/scenes/src/sketch/build.py --pack /path/to/pack.json \
    --out environments/threejs/scenes/03_sketchbook_airfield_constrained.html      # 58 MB
```

## World layout (for placing things)

Heights from a downward ray (`BenchmarkWorld.teleport(x, null, z)` uses the same rule):

* apron / pads / roads: y ≈ 14.8; character capsule centre stands 0.6 above the surface;
* the race-track bowl (x ±50) rises on embankments (17–19) to two 10 m wide grass bands at
  x = ±55..65, y = 21, which carry the retaining walls; the z = 0 service road passes through them in
  an open trench at y ≈ 11.1 (x ±32..±68) and ramps back up to the side zones;
* west zone: dirt oval pits at y ≈ 10–11 (x −150..−80, z −90..−20), stunt block rows at
  (−150..−90, 25..75); east zone: helipad (100,−83), hangar box (122..128, −93..−88), runway strip
  x 145..160, crater (76..113, 60..96, floor y ≈ 6);
* the plateau outside the walls (y = 21) holds the loop / mega ramps (z < −106 and z > 153).

## Verification (scratchpad scripts `sketch_shots2.py`, `sketch_probe2.py`, `sketch_tour.py`)

Headless Chromium (`--use-angle=gl-egl`): polish status `{props: 155, materials: 18, errors: [],
envMap: true}`, 60 fps without physics at 1280×800.  Keyboard walks (W for 2 s, ~3 m/s): open ground
6.1 m; into barrels / a road barrier / the tool cart / the fence 1.5–1.9 m and stopped at the
collider (fence from the east: x 143.5 → 140.27 with the fence at 140).

## AF bug suite (2026-09-08)

`bugs.js` holds 17 injected cases (`af01-float` … `af17-noshadow`), selected with `?bug=<id>` or by the harness
config's `bug`; `enhance.js` applies the case once the props are placed, exposes the judge answer as
`BenchmarkWorld.bug` and, in harness mode (`?harness=1&config=<name>`), installs the shared contract
`src/common/harness_page.js` (`window.__env`).  The harness spawn is the open tarmac north of the stone gate
(`SPAWN_DEFAULT`, yaw 0 = north); the game's own start stays inside the gate for the human walkthrough.
Configs + answers: `scripts/tools/gen_sketch_cases.py`; catalogue sheet: `scripts/tools/env_bug_shots.py sketch reports/airfield-suite/catalog`;
tasks `audit_afXX_bug` / `audit_af00_clean` (90 steps), judge GT in `judge/judge_sem.py`.
