# Beyond Fable Wilderness (source for `13_beyond_fable_wilderness_constrained.html`, v2)

Upstream: [xikhar/beyond-fable](https://github.com/xikhar/beyond-fable) (MIT) — a fully procedural
first-person wilderness (TypeScript + Vite + three r165): analytic terrain, procedural trees / grass /
rocks / water / sky, day-night cycle, weather, an "atmosphere console" (`~`).  No downloaded assets in
the upstream.  The original candidate (`orig_v1_*.bak`, 0.7 MB) was the unmodified Vite bundle plus the
benchmark boundary block.

`upstream/` is the upstream source with the changes below; it is rebuilt with the standalone Node in
`/mnt/data3/jingbo/tools/node` (no system node), see *Rebuild*.

## What changed (v1 -> v2)

* **Real PBR surfaces** (`src/procedural/SplatShader.ts`, `assets/textures.ts` generated by
  `make_textures_module.py` from Poly Haven CC0 sets, 1k JPEG data URLs, 4.9 MB):
  * terrain: four-way texture splat — meadow grass (`leafy_grass`), forest dirt (`forest_ground_04`),
    cliff rock (`rock_face_03`, triplanar), snow (`snow_02`) — blended by a new per-vertex weight
    attribute `aSplat` (`Biomes.getSplatWeights`, same masks as the vertex colours) and multiplied by the
    biome vertex colour, plus normal-map detail; the snow-trail deformation of the original material is
    kept.  Textures are uploaded raw and decoded in the shader (`pow 2.2`) so the brightness maths is
    exact: each set is normalised by its mean linear luminance and scaled to the albedo the scene's
    (strong) lighting was designed for — measured with reference spheres, not guessed.
  * boulders / stones / ruins: world-space triplanar rock (`rock_surface`, `rock_face_03`) — no UV seams
    on the displaced icosahedra, works with instancing.
  * tree trunks: `pine_bark` diffuse + normal (dark bark albedo ≈ 0.045); the tree-wind material now
    chains the base material's shader hook and keys its program per base material.
* **Player scale / feel** (`settings/global-defaults.json`): eye height 2.5 → 1.7 m, walk 5.5 → 4.2 m/s,
  sprint 15 → 8.5, jump 9 → 6.5, collision radius 0.5 → 0.35; grass blades 0.62 × height, 0.45 × width;
  far-terrain mesh 288 → 576 segments (less faceting on the horizon ranges).
* **Deterministic daylight** (`world/Environment.ts`): the session starts between 08:40 and 15:00 with
  mild weather (rain / low cloud / overcast are not picked at start), the day runs at 0.15× (a day ≈ 67
  min) and automatic weather changes are off — an episode keeps its lighting.  `?tod=0..1`,
  `?weather=clear|breezy|cloudy|lowclouds|overcast|rain`, `?seed=` still override; the console (`~`) and
  `R` still change everything live.
* **Controls / API** (`core/CameraController.ts`, `core/Game.ts`, `main.ts`): `yaw` / `pitch` /
  `pointerLocked` are public, `headless` lets keys drive the player without pointer lock;
  `window.BenchmarkWorld` = `{ version: 'beyond-fable-v2', ready, seed, scene, root, camera, renderer,
  actor, world, environment, hud, teleport(x, y|null, z), setView(yaw, pitch), setTime, setWeather,
  setDayCycleScale, setFlying, setHeadless, setHud, dismissOverlay, getState, addObject, reset }`.
  `?benchmark` (or `#benchmark`) skips the loading / click-to-enter overlays, hides the HUD and enables
  headless keys.  The page was already first person; the default human flow (loading screen → click →
  pointer lock) is unchanged.
* `index.html`: Google Fonts links removed (offline build).

## Files

* `build.py` — `npm run build` (tsc + vite) in `upstream/`, inlines the JS bundle and CSS into
  `dist/index.html`, adds the licence note and `boundary_block.html` (the benchmark boundary from the
  original candidate; kind `benchmark`, ±110 m around the spawn), writes the single-file HTML (5.6 MB).
* `make_textures_module.py` — Poly Haven texture sets → `upstream/src/assets/textures.ts`
  (data URLs + mean linear luminance per set).
* `../sketch/ph_fetch.py` downloads the sets into `assets/fable/textures/<id>/{Diffuse,nor_gl,arm}.jpg`.

## Rebuild

```bash
.venv/bin/python environments/threejs/scenes/src/sketch/ph_fetch.py --assets assets/fable \
    --tex leafy_grass forest_ground_04 rock_face_03 rock_surface snow_02 pine_bark
.venv/bin/python environments/threejs/scenes/src/fable/make_textures_module.py --assets assets/fable/textures \
    --out environments/threejs/scenes/src/fable/upstream/src/assets/textures.ts
cd environments/threejs/scenes/src/fable/upstream && PATH=/mnt/data3/jingbo/tools/node/bin:$PATH npm ci   # once
.venv/bin/python environments/threejs/scenes/src/fable/build.py \
    --out environments/threejs/scenes/13_beyond_fable_wilderness_constrained.html
```

## Verification (scratchpad `fable_tour.py`, `fable_close.py`, `fable_errs.py`, `fable_bench_test.py`)

Headless Chromium: no console errors / warnings, ~60 fps at 1280×800 ("high" quality preset).  Tour
screenshots at the spawn, meadow, forest, lake shore, hill top and aerial views (`?tod=0.5&weather=clear`)
before / after; reference-sphere brightness test (`fable_albedo_test.py`) used to calibrate the texture
gains.  The boundary script clamps teleports to ±110 m around the spawn, so the benchmark area is the
meadow / forest / lake zone around the origin; the mountains are scenery.

## WL bug suite (2026-09-08)

`upstream/src/benchmark/bugs.ts` holds 17 injected cases (`wl01-float` … `wl17-upsidedown`).  The world is
chunk-streamed and instanced, so every case is a *watcher*: whenever an InstancedMesh holding the target placement
appears (initial build or LOD rebuild) the mutation is re-applied; material cases detach the instance into its own
mesh and zero the instance.  Collision cases wrap `world.getCollidersNear` (air wall = a row of cylinders, ghost =
filtered cylinders) and swap the controller's terrain for a proxy (holes).  `main.ts` takes the world seed from the
harness config (`worldSeed: 7`, the world the carriers were picked in; a plain `?bug=` view defaults to seed 7) and
installs the shared harness contract (`src/common/harness_page.js`, injected by `build.py`).
Configs + answers: `scripts/tools/gen_fable_cases.py`; catalogue: `scripts/tools/env_bug_shots.py fable reports/wilderness-suite/catalog --extra "&seed=7"`;
tasks `audit_wlXX_bug` / `audit_wl00_clean`, judge GT in `judge/judge_sem.py`.
