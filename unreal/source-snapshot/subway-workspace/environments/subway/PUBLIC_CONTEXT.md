# Subway 公共场景约束

这是正常运营的现代城市地铁站，包含进站大厅、候车区和临轨站台。
评测期间列车固定停靠，不演示发车。场景不是博物馆、废墟或误导标识的解谜世界。

- 标准成人候车座椅应能正常落座，与同款座椅尺寸一致。
- 标注 CONTINUOUS EXHAUST / FIXED DIRECTION 的排风设备持续以固定方向运行；没有定时、感应或远程反转。
- 本站自动扶梯固定成对提供上行与下行通行；评测期间不实行全体单向运行的潮汐调度。
- 接触物体不会启动隐藏的电机。无人操作时，物体不会无故持续震动、改变属性或自动重生。

右上角小地图的黄色矩形是评测探索边界，边界阻挡不属于场景异常。
本文件提供判定所需的公开背景，不包含任务编号、答案或异常位置。
