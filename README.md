# WorldAuditBench project page

Published at https://ucsb-nlp-chang.github.io/WorldAuditBench/.

This branch contains the research website. The `main` branch contains the benchmark code.

## Develop and build

```sh
npm ci
npm run build
npm start
```

Open http://127.0.0.1:4173. Rebuild after editing source files.

- `src/app.jsx`: paper information, sections, result tables, and interactions.
- `src/style.css`: responsive styling.
- `src/taxonomy.jsx`: interactive anomaly taxonomy.
- `content.json`: anomaly descriptions, media paths, and environments.
- `media/`, `videos/`, `figures/`: benchmark demonstrations and paper figures.
- `assets/worldauditbench.pdf`: public preprint PDF.

The committed `assets/app.js` and `assets/app.css` are generated by the build. Commit updated bundles together with source changes. GitHub Pages serves this branch directly; no runtime build or external fonts are required.

## Publication details

The website lists the paper’s authors and affiliations with a concise citation section. The results reproduce the paper’s Table 2. Paper links open the [arXiv PDF](https://arxiv.org/pdf/2609.40325), and the citation includes arXiv:2609.40325 with a link to its abstract page.

Large dataset and environment resources are marked **Coming soon**, pending release on Hugging Face. Add their final links when they are published.

The Manrope font is distributed under the SIL Open Font License; see `assets/Manrope-OFL.txt`. Original demonstration videos are retained from the previous project page.
